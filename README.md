# Aditya Ujjwal — Portfolio

A dark, modern personal portfolio built with React + Vite.

## Sections
- Hero / intro
- Projects
- Skills
- 50-second elevator pitch
- Contact

## Project structure

```text
Aditya-Ujjwal-Portfolio/
├── public/
│   ├── profile.png
│   ├── pitch-poster.png
│   └── elevator-pitch.mp4   # add your 50-second video here
├── src/
│   ├── main.jsx
│   └── styles.css
├── index.html
├── package.json
└── README.md
```

## Run locally

```bash
npm install
npm run dev
```

Then open the Vite URL shown in the terminal, normally:

`http://localhost:5173`

## Production build

```bash
npm run build
npm run preview
```

## Important asset

Place the recorded 50-second elevator pitch at:

`public/elevator-pitch.mp4`

The page is already wired to `/elevator-pitch.mp4` and shows a clear fallback message if the file is missing.
